# Dashboard Page Design Overrides

## Page Purpose
Dashboard เป็นหน้าสรุปสถานะการเงินหลักสำหรับผู้ใช้งาน ต้องเน้นความชัดเจนของตัวเลขและความสบายตา

## Visual Rules
- ใช้พื้นหลังอ่อนและการ์ดสีขาวเพื่อแยกส่วนข้อมูล
- เน้นการ์ด summary, ตารางรายการ, และมุมมองพอร์ตอย่างชัดเจน
- ใช้เส้นแบ่งน้อยที่สุด และเพิ่มช่องว่างให้แต่ละบล็อก

## Typography
- หัวข้อใหญ่: `font-semibold` หรือ `font-bold`
- ข้อความเนื้อหา: `font-medium` หรือ `font-normal`

## Colors
- ปุ่ม CTA: `#2563EB`
- พื้นหลังหน้า: `#FAFAFA`
- สีข้อความหลัก: `#09090B`
- สีข้อความรอง: `#475569`

## Motion
- ใช้ transition สำหรับปุ่มและการ์ด
- ไม่ใช้งาน animation แบบเคลื่อนไหวเร็วเกินไป
- ปิด animation ถ้า `prefers-reduced-motion` เปิดใช้งาน
